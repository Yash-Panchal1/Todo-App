# ✅ To-Do App

A simple and clean To-Do List application built using **HTML**, **CSS**, and **JavaScript**. Add, manage, and track your daily tasks with ease!

## 🚀 Features

- ➕ Add new tasks
- ✔️ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Persistent storage using LocalStorage
- 📱 Fully responsive design
- 🎨 Clean and minimal UI

## 🛠️ Built With

- **HTML5** – Structure
- **CSS3** – Styling
- **JavaScript (Vanilla JS)** – Functionality
